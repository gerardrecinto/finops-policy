What is real, and what is not verified.

Every claim on this page comes from a command that ran. Anything that did not run is listed on the right.

Verified

  • 8 pytest tests pass. They load AWS, Azure and GCP rows into SQLite and run every query.
  • 4 OPA tests pass on opa 1.22. shellcheck and terraform fmt are clean.

Not verified

  • The Sentinel policy and the Infracost step did not run: no Sentinel or Infracost CLI and no cloud credentials.
  • The SQL runs on SQLite. BigQuery and Azure SQL need small changes, such as JSON_VALUE.
  • Provider rows are shaped from documented export fields, not a real export file, and FOCUS 1.x has more required columns.
  • terraform validate was not run. The commitment model ignores term length, upfront payment and instance-family limits.

Questions before you try it.

Why commit to a low percentile?

Usage above the commitment stays on-demand, but an unused commitment still bills every hour. Committing near the floor keeps utilization at 100 percent.

Why both OPA and Sentinel?

Teams use one or the other. The tag rule is written twice so either can be adopted. Only the OPA version ran here.

Is this connected to a real bill?

No. The tests use small sample rows. Point the normalizer at a real export to try it.
